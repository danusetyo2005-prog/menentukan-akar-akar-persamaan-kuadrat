## Deskripsi

Repository ini berisi tugas mata kuliah **Algoritma dan Pemrograman** mengenai pembuatan program Python untuk menentukan akar-akar persamaan kuadrat menggunakan **Rumus ABC**.

Program dibuat untuk menerima nilai koefisien persamaan kuadrat, kemudian menghitung dan menentukan akar-akarnya berdasarkan nilai diskriminan.

## Daftar File

### 1. `pertemuan 1/`
Folder yang berisi file atau materi yang berkaitan dengan kegiatan dan tugas pada **Pertemuan 1**.

### 2. `Tugas pertemuan 1 algoritma dan pemrogram...`
File tugas yang berisi materi atau hasil pengerjaan tugas **Algoritma dan Pemrograman Pertemuan 1**.

### 3. `diagram alur.png`
File gambar yang berisi **diagram alur (flowchart)** dari proses atau langkah-langkah algoritma program untuk menentukan akar-akar persamaan kuadrat.

### 4. `tugas algoritma dan pemrograman 1.py`
File program Python yang digunakan untuk **menentukan akar-akar persamaan kuadrat menggunakan Rumus ABC**.

Program menggunakan koefisien:
- `a` = koefisien x²
- `b` = koefisien x
- `c` = konstanta

Kemudian program menghitung diskriminan dengan rumus:

**D = b² - 4ac**

Berdasarkan nilai diskriminan, program menentukan jenis dan nilai akar persamaan kuadrat.

## Tujuan

Tujuan pembuatan tugas ini adalah untuk memahami penerapan **algoritma, flowchart, dan bahasa pemrograman Python** dalam menyelesaikan permasalahan matematika, khususnya menentukan akar-akar persamaan kuadrat.
